# Audio-e-book-reader

📚 Audio E-Book Reader

📌 Project Overview

The Audio E-Book Reader is a Python-based application that converts PDF documents into audio files using Text-to-Speech (TTS) technology. It extracts text from PDF files and converts the extracted content into MP3 audio, allowing users to listen to e-books and documents conveniently.

✨ Features

Extract text from PDF documents.

Convert extracted text into speech using Google Text-to-Speech (gTTS).

Generate MP3 audio files automatically.

Supports English text-to-speech conversion.

Saves generated audio files for later listening.

🛠️ Technologies Used

Python

PyPDF

gTTS (Google Text-to-Speech)

⚙️ Installation and Setup

Clone the repository:

git clone https://github.com/ChepuriBhargavi-gif/Audio-e-book-reader.git

Navigate to the project directory:

cd Audio-e-book-reader

Create a virtual environment (optional):

python -m venv venv

Activate the virtual environment:

Windows:

venv\Scripts\activate

Install the required dependencies:

pip install -r requirements.txt

▶️ How to Run

Place your PDF file inside the project folder.

Update the PDF filename in the Python script if required.

Run the application:

python main.py

The extracted PDF content will be converted into speech.

The generated MP3 file will be saved in the project directory.

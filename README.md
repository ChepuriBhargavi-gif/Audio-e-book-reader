# Audio-e-book-reade

📚 Audio E-Book Reader

📌 Project Overview

The Audio E-Book Reader is a Python-based application that converts PDF documents into audio files using Text-to-Speech (TTS) technology. It extracts text from PDF files and converts the extracted content into MP3 audio, allowing users to listen to e-books and documents conveniently.

✨ Features

Extract text from PDF documents.

Convert extracted text into speech using Google Text-to-Speech (gTTS).

Generate MP3 audio files automatically.

Supports English text-to-speech conversion.

Saves generated audio files for later listening.

🛠️ Technologies Used

Python

PyPDF

gTTS (Google Text-to-Speech)
